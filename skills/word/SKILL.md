# Word

在当前 Workspace 的同一 Word 文件上完成读取、创建、编辑、翻译、复核和导出 PDF。最终交付为 DOCX 文件，不是网页。

- `create`：一次提交完整 `content` 节点（heading、paragraph、list、table、image、page_break），不要逐页重复创建。图片使用 `kind:image, meta:{file_id:"当前空间受管图片ID"}`，禁止编造网络地址。
- `read`：传 `file_id`，返回正文和 `sha256`。所有编辑先读取当前版本。
- `edit`：传 `file_id`、`expected_sha256`。局部修改/翻译优先传 `replacements:[{old:"精确原文",new:"替换内容"}]`，保留其他段落、图片和样式。每个 old 必须在一个段落内唯一匹配；无法安全定位时重新读取或说明限制，不能擅自替换整份文件。
- 只有用户明确要求完整重排时才在 edit 中传完整 content；完整重写不保留未提交的复杂布局、批注和修订，不得声称无损。
- `to_pdf` 导出新的 PDF，不覆盖 DOCX；`review` 可重新检查原文件。

翻译不是独立 Skill：读取→由 AI 翻译→精确写回。生成/修改/转换后系统自动将实际文件渲染为页面图，交给视觉模型复核。`review.status=completed` 只代表检查完成，逐页结论才决定是否有缺陷；unavailable 表示未完成，必须如实说明。仅修复问题位置，最多两轮，不得因复核重建整份文件。

## 原生文档与逐页检查

始终由原生 DOCX 节点生成段落、表格、图片与分页，不通过 HTML 中转。生成前规划标题层级、纸张、页边距、正文字号与表格宽度；长表格避免压缩字体以强行挤入一页。系统复核必须覆盖所有实际渲染页，不能用计划章节数代替页数。

修复时按逐页问题报告定位原文，先 read 当前版本，使用 Word replacements 最小替换；不得调用 PPT patches 或为了通过检查重新 create 文档。对需要样式或复杂表格结构变更、现有接口无法安全表达的问题，保留原文件并明确告知限制，不声称已修复。最多两轮，仍有问题时列出页码和问题；复核不可用时交付状态必须明确为未完成检查。
