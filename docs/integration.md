# 集成与独立边界

本包不导入 `app.*`，不调用 QuickerWrite API、不读取平台环境密钥。纯原生 Word/PPT 生成器从原服务端抽离，使用可覆盖的文档默认值。本仓库是独立维护源；服务端可固定版本安装，或通过受审查的 revision vendoring 引入。

旧 worker 协议：`qw-documents-worker --format docx|pptx|xlsx`，stdin 二进制输入，stdout 成功 PDF，stderr 错误。调用方必须检查退出码，不能将错误输出当成 PDF。取消支持由 Python 转换函数回调提供。

服务端适配层继续负责 file_id 解析、用户权限、存储、任务队列、执行配额、用户交互和审计。公共技能不能假定这些私有工具存在。需要平台交互约定时，在应用自身的技能适配说明中保留，而不要写入通用技能入口。

不要在导入该包时启动服务。升级先在隔离环境运行测试和真实转换，再固定版本/提交；不要让生产服务跟随可变 main 分支。安全过滤不等于进程隔离，多租户运行使用无网络、非 root、只读根文件系统和受限临时空间的容器。
